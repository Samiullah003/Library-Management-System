# 📚 Library Management System

A full-stack web application built to simplify library operations and manage book records efficiently.

## 🚀 Technologies Used
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Java
- **Database:** MySQL
- **Server:** Apache Tomcat 10+

## ✨ Features
- Add new books
- View book records
- Update book details
- Delete book records
- MySQL database integration
- User-friendly interface

## ⚙️ Setup and Installation

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Configure your MySQL database credentials in the backend configuration file.
3. Install frontend dependencies:
   ```bash
   npm install
   ```
4. Start the React frontend:
   ```bash
   npm start
   ```
   If the project uses Vite, run `npm run dev` instead.
5. Run the Java backend using your configured Java server or build tool.

## 🎯 Objective
To develop an efficient library management application using full-stack technologies and database operations.

# Library Management System

> **Abstract** : The Library Management System is a web-based application developed using HTML, CSS, JavaScript, Java, and MySQL. It helps librarians manage book records, student details, book issuing and returning, and book availability through a simple and user-friendly interface. The system reduces manual work and maintains library records efficiently.
